# 🩺 HypnoCare
_A Smart Mobile App for Personal Health Management_

📱 **BMI • Diet • Sodium • AI Chatbot**  
ช่วยดูแลสุขภาพในชีวิตประจำวันอย่างเป็นระบบ

---

</div>

## ✨ Overview
แอปพลิเคชันนี้ถูกออกแบบมาเพื่อช่วยผู้ใช้งานติดตามและดูแลสุขภาพของตนเอง  
โดยรวมฟีเจอร์สำคัญด้านโภชนาการ การคำนวณสุขภาพ และ AI Chatbot ไว้ในแอปเดียว
